# 🏡 Airbnb Predictive Classification Model

### 📌 Project Overview
This project focuses on building a predictive classification model using Airbnb property and host data to determine key listing outcomes. The goal of this repository is to demonstrate an end-to-end machine learning lifecycle, from exploratory data analysis (EDA) and rigorous feature selection to model tuning and serialization.

### 🛠️ Technical Stack & Methodology
* **Language:** Python
* **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn
* **Feature Engineering:** Implemented `SelectKBest` to identify and isolate the most statistically significant predictive features, reducing dimensionality and preventing overfitting.
* **Model Architecture:** Logistic Regression
* **Hyperparameter Tuning:** Utilized `GridSearchCV` to systematically search and identify the optimal hyperparameter combinations, maximizing the model's predictive accuracy.
* **Serialization:** Model serialized using Python's `pickle` library for scalable, rapid deployment. 

### 🚀 Key Results
* Successfully engineered a robust data pipeline capable of handling missing values, encoding categorical variables, and normalizing numerical features.
* Deployed an optimized Logistic Regression model that balances high precision and recall for predictive classification tasks.
